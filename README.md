# app-data

여러 앱이 함께 쓰는 **데이터 저장소**. 로컬에서 공공 OpenAPI를 수집해 JSON으로 가공하고
`data/<앱>/` 아래에 커밋한다. 앱은 이 JSON을 받아 로컬 DB에 캐싱한다.

앱이 API를 직접 호출하지 않으므로 **일일 호출 한도에 걸리지 않고**, 원본 API 스펙이 바뀌어도
**앱을 다시 배포할 필요 없이** 수집기만 고치면 복구된다.

## 구조

```
apps/<앱>/collect.py     수집기 (앱마다 하나)
data/<앱>/*.json         앱이 받아가는 결과물
refresh.bat              수집 → 변경 시 커밋/푸시
```

## 앱에서 받는 URL

```
https://raw.githubusercontent.com/leeedaebok/app-data/master/data/<앱>/<파일>.json
```

현재 등록된 앱:

| 앱 | 파일 | 내용 | 원본 |
|---|---|---|---|
| gonggoalimi | `data/gonggoalimi/notices.json` | 모집중 사업공고 | K-Startup (data.go.kr 15125364) |

## 갱신 방법

### 원클릭 (권장)

```bat
refresh.bat              REM 모든 앱
refresh.bat gonggoalimi  REM 특정 앱만
```

수집 → 변경이 있으면 자동으로 커밋·push 한다. 수집이 실패하면 푸시하지 않는다.

### 자동화 (Windows 작업 스케줄러)

하루 1회면 충분하다. 공고 접수기간이 중앙값 30일이라 하루 지연으로 놓치는 건이 사실상 없다.

1. 작업 스케줄러 → 기본 작업 만들기 → 트리거: 매일 (예: 오전 6시)
2. 동작: 프로그램 시작 → `refresh.bat` (시작 위치 = 이 폴더)
3. 인증키가 필요한 앱은 시스템 환경변수를 미리 등록해 둘 것.

## JSON 형식

모든 앱이 같은 봉투를 쓴다. 배열을 그대로 두지 않고 감싸는 이유는, 앱이 받자마자
건수와 생성시각으로 **온전한 파일인지 판단**할 수 있게 하기 위해서다.

```json
{
  "schema": 1,
  "app": "gonggoalimi",
  "source": "kstartup",
  "generated_at": "2026-08-14T06:00:00+09:00",
  "count": 293,
  "notices": [ { "...": "원본 필드명 그대로" } ]
}
```

- `schema` — 형식이 바뀌면 올린다. 앱은 모르는 버전이면 캐시를 유지하는 편이 안전하다.
- `count` — `notices` 길이와 반드시 같다. 다르면 잘린 파일이다.
- 레코드의 **필드명은 원본 API 그대로** 둔다. 앱의 기존 파싱·분류 코드를 그대로 쓰기 위해서다.

## 새 앱 추가하기

1. `apps/<앱>/collect.py` 를 만든다. `apps/gonggoalimi/collect.py` 를 복사해 수집 부분만 고치면 된다.
2. 결과를 `data/<앱>/<파일>.json` 에 위 형식으로 쓴다.
3. 위 표에 한 줄 추가한다.

`refresh.bat` 은 `apps/*` 를 자동으로 순회하므로 따로 등록할 것이 없다.

### 수집기가 지켜야 할 것

앱이 **죽지 않은 채 고장 나는** 상황을 막는 장치다. 크래시 리포트로는 잡히지 않는 유형이라
수집 단계에서 걸러야 한다.

- **결과가 0건이면 중단** — 빈 파일을 커밋하지 않는다.
- **직전 대비 절반 아래로 줄면 중단** — 원본 이상이 의심되면 기존 파일을 유지한다.
- **서버측 필터가 무시되면 중단** — 조건 필터를 무시한 응답을 정상으로 받아들이면
  목록이 조용히 엉뚱한 내용으로 바뀐다.

실패하면 0이 아닌 종료코드를 남길 것. `refresh.bat` 이 그걸 보고 푸시를 멈춘다.

## 앱 쪽 권장 처리

- 받은 `count` 와 실제 배열 길이를 대조하고, 어긋나면 **기존 캐시를 유지**한다.
- `generated_at` 이 지나치게 오래됐으면(예: 3일 이상) 수집이 멈춘 것이므로 로그를 남긴다.
- 내려받기에 실패하면 원본 API 직접 호출 → 로컬 캐시 순으로 물러난다.
